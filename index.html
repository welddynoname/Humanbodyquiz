How it works

1. The host creates a room and shares the 6-character code.

2. Players join using the code and a nickname.

3. The host starts the quiz and advances questions.

4. Everyone sees the live leaderboard. Correct answers earn 100 points.

Each player should use a separate browser/device. Rejoining with the same browser session restores that player's identity.
